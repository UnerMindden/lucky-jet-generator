# Lucky Jet — генератор случайных коэффициентов

Готовая веб-часть мини-приложения в стиле референса. Весь интерфейс и генерация работают в браузере.

## Что реализовано

- Генерация по кнопке «Получить сигнал» / «Get signal».
- Случайные коэффициенты от **1.10× до 10.00×** включительно, с двумя знаками после точки.
- Равномерное распределение по указанному диапазону.
- Анимация длительностью **3 секунды**. Во время неё кнопка блокируется.
- Переключатель **RU / EN**. Выбор языка сохраняется в браузере.
- Фиолетовый адаптивный дизайн и встроенное изображение персонажа.
- Подпись о случайной генерации и отсутствии связи с реальными игровыми раундами.
- С учётом настройки уменьшения анимации на устройстве.

Кнопок перехода в казино нет. Случайные значения не связаны с реальными раундами Lucky Jet и не являются прогнозами. Подключений к игровым API нет.

## Как загрузить в Git

1. Распакуй архив.
2. Загрузи **содержимое** в корень своего репозитория: `index.html`, `styles.css`, файлы `.mjs`, папку `assets` и остальные файлы.
3. `index.html` должен лежать в корне репозитория.
4. Размещай как статический сайт. Установка зависимостей и команда сборки не нужны. Каталог публикации — корень с `index.html`.

Файлов и настроек Sites в архиве нет. Все изображения локальные, пути относительные, внешние библиотеки не загружаются.

## Проверить на компьютере

Открой терминал в распакованной папке:

```sh
python3 -m http.server 8080
```

Затем открой `http://localhost:8080`. Запускай через сервер, потому что JavaScript использует модули.

Необязательная проверка генератора с установленным Node.js:

```sh
node --test checks/generator.test.mjs
```

## Подключить к Telegram

После размещения полученный **HTTPS-адрес** можно указать как URL мини-приложения в настройках твоего бота через **@BotFather**. Архив содержит интерфейс мини-приложения; он сам не создаёт Telegram-бота и не настраивает его аккаунт.

Токен бота не нужен для работы этой веб-части. Не добавляй секретные токены в HTML, JavaScript или публичный Git-репозиторий.

## Файлы

- `index.html` — экран мини-приложения.
- `styles.css` — оформление и адаптация под телефон.
- `app.mjs` — переключение языка и анимация генерации.
- `generator.mjs` — диапазон, длительность и генератор случайных значений.
- `assets/jet-pilot.png` — иллюстрация персонажа.
- `assets/icon.svg` — иконка вкладки.
- `ASSETS.md` — описание и исходный запрос генерации иллюстрации.
- `checks/generator.test.mjs` — проверка диапазона и случайной выборки.
